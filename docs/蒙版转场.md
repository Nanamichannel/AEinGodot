# 蒙版转场：从 AE 到 Godot 的全流程

> 场景：用角色移动带动蒙版，把「上一屏」擦掉，露出「新界面」。
> 上一屏在转场过程中**还在动**，所以不能抓一帧图，要实时渲染。

---

## 0. 先理解一件事

蒙版在 AE 里是**路径数据**（贝塞尔曲线），不是像素。

导出器把它采样成多边形，同时给出两套坐标：

| 字段 | 坐标系 | 用在哪 |
|---|---|---|
| `masks[].points` / `frames` | 图层坐标（原点=图层左上角） | 裁**自己这一层**（普通静态蒙版） |
| `masks[].compPoints` / `compFrames` | 合成坐标（原点=画布左上角） | 转场用，贴在任意节点上都对得上 |

转场必须用 `compFrames`——因为蒙版挂在哪个层上是随便的，合成坐标才不会跟着跑。

---

## 1. AE 里怎么摆

```
合成
├ 角色（做运动的那个，可以关眼，只要有运动数据）
├ 转场遮罩（空物体或纯色，蒙版画在它上面）
└ _预演截图（占位用的上一屏截图，导出前关眼）
```

要点：

1. **蒙版画在 `转场遮罩` 上**，靠它自己动或父级动都可以
2. 蒙版可以用钢笔工具画曲线，导出时会自适应细分（误差 ≤0.4px）
3. 那张截图只是为了在 AE 里看效果，**关眼即可**，不会进 json
4. 蒙版的图层名建议带 `遮罩` 或 `mask`，方便找

---

## 2. 导出

`文件 > 脚本 > 运行脚本文件` → `export-motion-engine.jsx`

导出后的 json 里能看到：

```json
{
  "name": "空 10", "type": "null",
  "masks": [{
    "animated": true,
    "points":      [[49,50], ...],              // 图层坐标（10 个点）
    "compPoints":  [[911,490], ...],            // 合成坐标
    "frames":      [[0,[...]], [33,[...]]],     // 图层坐标，逐帧
    "compFrames":  [[0,[...]], [33,[...]]]      // 合成坐标，逐帧
  }]
}
```

`frames` 只存**形状变化的帧**，所以不会爆。

---

## 3. 导入 Godot

面板里选 json / 素材目录 / 输出场景 → 点「生成」。

带动蒙版的层会额外生成：

```
MaskRigs (Node2D)
└ Mask_空 10            (SubViewport, 合成尺寸的一半, 透明底, 每帧更新)
   └ MaskPoly           (Polygon2D, 白色, 多边形逐帧写入)
```

日志里会写：

```
✓ 蒙版已应用 1 层：空 10(动蒙版→MaskDriver)
```

> SubViewport 用半分辨率：边缘略软一点，开销只有全分辨率的 1/4。
> 蒙版的点会按比例缩放后写进 Polygon2D。

---

## 4. 接线（一次性，三步）

### ① 上一屏要实时渲染

```
你的上一屏场景
└ SubViewport (尺寸 1920×1080, update=ALWAYS)
   └ 上一屏的根节点
Sprite2D  ← texture = 上面那个 SubViewport 的 ViewportTexture
```

### ② 给这个 Sprite2D 上遮罩材质

- 选中 Sprite2D → `Material` → 新建 **ShaderMaterial**
- Shader 选 `res://addons/ae_motion/mask_tex.gdshader`

### ③ 挂 `mask_apply.gd`

- 右键 Sprite2D → 附加脚本 → 现有脚本 → `mask_apply.gd`
- 检查器里 **Mask Viewport** 指向 `MaskRigs/Mask_空 10`

`mask_apply.gd` 在 `_ready` 里把视口纹理绑到材质的 `mask_tex` 上，之后自动更新。

---

## 5. 运行时控制

- 蒙版动画一直在跑（`mask_rig.gd` 的 `_process`）
- 想暂停/开始：设 `Mask_空 10` 的 `enabled`
- 想循环：勾 `loop`
- 想整体反转（留外面、裁里面）：材质或脚本里勾 `invert`

转场开始前建议先 `enabled = false`，等要开始的那一刻再打开，避免时间对不上。

---

## 6. 成本

| 方案 | 每像素成本 | 点数上限 |
|---|---|---|
| uniform 传点（旧） | 遍历 N 个点 | 512 |
| **SubViewport 纹理（现在）** | **1 次采样** | 无限制 |

半分辨率视口：1920×1080 的四分之一填充量，一般 <0.2ms。

---

## 7. 排查表

| 现象 | 原因 |
|---|---|
| 蒙版整体偏移 | 用的是 `points` 而不是 `compFrames`；或者 json 是旧版导出（没有 compFrames） |
| 蒙版不动 | `MaskRigs/Mask_*` 的 `enabled` 是 false，或 json 里 `animated=false` |
| 画面全被裁掉 | 多边形点数 <3，或点的坐标全在画面外（检查图层 position） |
| 画面完全没被裁 | 目标 Sprite2D 的材质不是 `mask_tex.gdshader`，或 `mask_viewport` 没指对 |
| 边缘呈锯齿 | 视口是半分辨率；要更硬就改成全分辨率（导入器里 `vp.size`） |
| 蒙版位置对、但形状钝 | 多边形被抽稀（>480 点）；调低导出容差或提高上限 |
