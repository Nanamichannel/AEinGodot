AI 规则（每个新会话先读这份）
================================================================

这份文件是常驻约束，不需要我每次重写。你按它做就行。
数据说明看 ae-motion.md，本文件只管“怎么做才不返工”。

----------------------------------------------------------------
0. 工作方式
----------------------------------------------------------------
1. 顺序永远是：读 ae-motion.md → 读 json → 输出映射表 → 等我确认 → 写代码。
   跳过映射表直接写代码 = 重做。
2. 映射表一行一个 json 层，按 z 排序，列：
   z | name | type | isStatic | parent | blend.mode | 贴图文件名 | Godot 节点路径
3. 不确定就停下来问。猜错的代价比问一句高得多。
4. 不要修改我给的 json 和贴图，只读。

----------------------------------------------------------------
1. 层级
----------------------------------------------------------------
1. z 是 AE 图层序号：1 在最前面（最上层），数字越大越靠后。
   Godot 里要么按 z 从大到小添加节点（先加最底，后加的在上），
   要么 z_index = -z。不要按"z 大在上"建，会把整屏盖死。
2. parent 字段是父层的 index，按它建父子关系。
3. type="null" 的层没有画面，用空 Node2D，不要建 Sprite2D。
4. 不要拍平层级，不要自己做世界坐标换算。
5. 根节点放在 (0,0)，不加缩放。画布尺寸取 clip.comp。

----------------------------------------------------------------
2. 变换
----------------------------------------------------------------
1. position 单位 px，是父级空间的坐标，直接赋给 Node2D.position。
2. rotation 单位是度，用前乘 PI/180 换成弧度。
3. scale 是比值，1.0 = 100%，直接用。
4. 采样点已经是最终结果，一律线性插值，不要再套贝塞尔曲线。
5. 时间单位毫秒，动画总长 = clip.length 秒。

----------------------------------------------------------------
3. 贴图
----------------------------------------------------------------
1. 文件名 = asset.source 里斜杠 "/" 前面的部分。
   例："人物3/开始页面.psd" → 人物3.png
2. 遇到同名层，用 id 或 index 区分，不要用 name 或 source 当唯一键。
3. 摆放只有一条公式，每个 Sprite2D 都要写：
       centered = false
       offset = -(Vector2(anchor) - Vector2(left, top))
4. anchor 可能是负数、可能落在图层边界外面（例如 [-327.5, 306]）。
   原样代入公式，不要 clamp，不要取绝对值，不要“修正成一个合理的值”。
5. 贴图尺寸必须等于 json 的 width×height。
   如果 PNG 比 json 小（PS 裁剪裁掉了透明边），不要缩放，用这条修正：
       offset = -(Vector2(anchor) - Vector2(W_json - W_png, H_json - H_png))
   尺寸相等时它等价于 offset = -anchor。

----------------------------------------------------------------
4. 透明度
----------------------------------------------------------------
1. alpha 驱动 self_modulate.a，绝对不要用 modulate。
   AE 的图层不透明度不向下继承，Godot 的 modulate 会往下乘。
2. 父级动画不负责把透明度传给子级。

----------------------------------------------------------------
5. 静态层
----------------------------------------------------------------
1. isStatic=true 的层整段不动，不要给它建动画轨道。
2. 只给采样点数量大于 1 的通道建轨道。
3. inPoint / outPoint 之外的区间，不要让那层出现。

----------------------------------------------------------------
6. 混合模式（只有 json 里出现非 NORMAL 时才需要）
----------------------------------------------------------------
1. 先扫一遍 json：有没有 blend.mode 不是 "NORMAL" 的层。
   全 NORMAL 就跳过本节，不需要着色器。
2. 有混合层时，实现必须用 blend_modes.gdshaderinc 里的函数，
   直接 #include，不要自己推导混合公式。
3. 每个非 normal 的混合层，前面必须有 BackBufferCopy 节点，
   同一个 CanvasLayer，树里排在它之前。少了它画面整块变黑或变亮。
4. 合成公式只有一个：
       out = mix(backdrop, blend(backdrop, source), alpha * layer_opacity)
   透明度在混合之后插值，写成 blend(cb, cs * opacity) 是错的。
5. channelPlan = "multiplier" 的层，纹理初始值填 1.0，不是 0.0。
6. blend.group 相同的层属于同一个合成上下文，BackBufferCopy 按组插入。
7. HUE / SATURATION / COLOR / LUMINOSITY 四族没有逐层实现，
   必须预合成，不许硬写。
8. AE 里这些层用的是 Classic 变体（blend.classic = true），
   着色器按 sRGB 算，不要自己转到线性空间。

----------------------------------------------------------------
7. 不做什么
----------------------------------------------------------------
1. json 的 unsupported 列表是硬约束：里面的功能必须明说“我不实现”，
   并给出替代方案，不许假装实现了。
2. 不要自己发明交互、音效、震动、粒子、过场。
3. 交互我只描述“看到什么现象”，怎么实现由你决定，但不要超出我描述的范
   围。

----------------------------------------------------------------
8. 交付
----------------------------------------------------------------
1. 一个场景，层级和 json 一致；一个 AnimationPlayer；一个可调用的播放函数。
2. 附一段自检，逐条回答：
   - 节点数 == json 层数？
   - 每张贴图都找到了？尺寸对得上？
   - 父级链和 json 的 parent 一致？
   - 静态层有没有被误加轨道？
   - anchor 有没有被 clamp 过？

----------------------------------------------------------------
9. 最容易犯的六个错（别犯）
----------------------------------------------------------------
1. 把父子拍平 —— 挂在空对象下面的层会乱飞。
2. 用 modulate 做透明度 —— 子层会跟着一起变。
3. 给 anchor 取绝对值 —— 旋转时整张图甩出去。
4. 给静态层建轨道 —— 数据量翻十倍，还没效果。
5. 把 null 层建成 Sprite2D —— 凭空多出一个白方块。
6. 混合层忘了 BackBufferCopy —— 整屏黑，而且很难查。
