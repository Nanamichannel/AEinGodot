AE Motion —— Godot 编辑器插件
================================================================

装到新工程（三步）
----------------------------------------------------------------
1. 把整个 addons\ae_motion 文件夹复制到新工程的根目录下
   （新工程里应该有 addons\ae_motion\plugin.cfg）
2. Godot 打开工程 → 项目 > 项目设置 > 插件
   → 找到 "AE Motion" → 启用
3. 编辑器右侧出现「AE Motion」面板

用法
----------------------------------------------------------------
面板里三行，从左到右：

1. AE 导出的 json
   点 "…" 选 AE-Motion-Export 里的 json。
   可以在工程外面，插件直接用绝对路径读。

2. 素材目录（项目内）
   点 "…" 选 PNG 所在文件夹。
   必须在 res:// 下 —— Godot 只能加载导入过的纹理，
   所以先把 PNG 文件夹复制进工程，等它导入完成再选。

3. 输出场景（项目内）
   选 json 后会自动填 res://generated/<json名>.tscn，可以改。

三项都填好后自动生成（面板上「选完自动生成」默认开着），
生成完自动打开场景，按 F6 就能看。

出问题看面板下面的日志框
----------------------------------------------------------------
- "缺贴图 N 张：xxx"  → 图层名和 PNG 文件名对不上
- "找不到素材目录"     → 选的不是 res:// 路径，或者还没导入完
- "找不到 JSON"        → 路径里有中文没问题，检查文件是否被移动

注意
----------------------------------------------------------------
- 生成的场景会被整个覆盖，不要手改；要加东西就包一层主场景，
  用「实例化子场景」引用它。
- 换界面就换一个输出场景名，别让两个界面互相覆盖。
- 面板里的路径不会跨重启保存，每次重开工程要重新选一次。
